# Автопоиск кандидатов «как в LinkedIn» через провайдеров данных

Дополнение к `PLAN.md`, раздел 1.3. Дата: 2026-10-08.

## 1. Что это такое

People Data Labs (PDL) и Coresignal собирают публичные профессиональные профили из многих источников: открытый веб, профессиональные сети, резюме, соцсети. Они приводят их к единому формату и продают доступ через API.

В одной записи примерно то же, что видно в профиле LinkedIn:
- имя, текущая должность и компания, город и страна;
- история работы с датами и описаниями должностей;
- образование, навыки;
- **ссылка на LinkedIn-профиль**.

Важно: это **не живой LinkedIn**, а снимок. Базы обновляются примерно раз в месяц.

## 2. Как это работает по шагам

```
Вакансия + требования в таблице
        │
        ▼
1. Claude превращает требования в фильтр поиска
   (страна/город, синонимы должности, навыки, уровень, стаж) → HR видит фильтр
        │
        ▼
2. Пробный запрос: «сколько людей подходит под фильтр?»
   слишком много → сужаем, слишком мало → расширяем
        │
        ▼
3. Забираем N полных профилей (например, 100) ← здесь тратятся деньги
        │
        ▼
4. Код убирает дубли и тех, кого уже показывали раньше (SQLite)
        │
        ▼
5. Claude оценивает каждого по чек-листу вакансии (как отклики с hh/Indeed)
        │
        ▼
6. В лист кандидатов попадают лучшие 30–50 со ссылкой на LinkedIn,
   баллом и обоснованием
        │
        ▼
7. HR открывает ссылку и смотрит живой профиль (он актуальнее базы).
   Затем отправляет запрос в друзья или InMail
        │
        ▼
8. Повторный запуск раз в неделю: показываем только новых людей
```

Пример фильтра для вакансии «Senior Interior Designer, Dubai» (условно, на языке запросов Elasticsearch, который понимают оба провайдера):

```json
{
  "bool": {
    "must": [
      {"term":  {"location_country": "united arab emirates"}},
      {"match": {"job_title": "interior designer"}}
    ],
    "should": [
      {"match": {"skills": "3ds max"}},
      {"match": {"skills": "corona renderer"}},
      {"match": {"job_title": "senior"}}
    ]
  }
}
```

Фильтр — грубое сито: он отбирает «интерьерных дизайнеров в ОАЭ». Тонкую оценку (жилые интерьеры, стаж 5+ лет, портфолио) делает Claude по чек-листу.

## 3. Сравнение провайдеров

| | People Data Labs | Coresignal |
|---|---|---|
| Размер базы | ~1,5–3 млрд профилей (оценки расходятся) | ~890 млн записей сотрудников (multi-source) |
| Обновление | раз в месяц | заявлены более свежие данные, есть поле «когда замечена смена работы» |
| Полезные поля | должность, роль и уровень (стандартизированы), история работы, образование, локация, `linkedin_url` | `headline`, `summary`, история работы с описаниями, inferred skills, общий стаж в месяцах, прогноз зарплаты, `linkedin_url` |
| Запросы | Elasticsearch или SQL | Elasticsearch DSL |
| Оплата | 1 кредит = 1 полученный профиль, пустой ответ бесплатен | 10–20 кредитов за запись сотрудника |
| Цена (ориентир, проверить) | Pro от $98/мес, ~$0,28 за профиль; бесплатно ~100 профилей в месяц | Mini $49/2 500 кредитов, Starter $199/12 000, Pro $499/35 000. Предпросмотр поиска только с Pro. Триал 7 дней, 2 000 кредитов |
| Ограничения | 10 запросов поиска в минуту по умолчанию | — |

Цены взяты из официальных страниц и обзоров 2025–2026 годов. Данные местами расходятся, перед покупкой нужно сверить.

## 4. Сколько стоит одна вакансия

100 профилей на вакансию:
- PDL: 100 × ~$0,28 ≈ **$28**
- Coresignal (multi-source, 20 кредитов, тариф Starter): 100 × 20 × $0,0166 ≈ **$33**
- Оценка через Claude: центы за профиль, **~$1–2** на всю пачку

Итого **~$30–35 на вакансию за первый прогон**. Повторные прогоны дешевле, потому что забираем только новых.

## 5. Ограничения (честно)

1. **Данные не живые.** Человек мог сменить работу месяц-два назад. Ничего страшного: HR всё равно открывает живой профиль перед тем, как писать.
2. **Покрытие ОАЭ неизвестно.** Провайдеры не публикуют цифры по странам. Это главное, что нужно проверить на пилоте.
3. **Нет портфолио.** Для дизайнеров это важно: в базе нет картинок, проектов и постов. Поэтому оценка — предварительный отбор. Для топ-кандидатов можно сделать глубокую оценку: HR делает «Save to PDF» в LinkedIn и отправляет в бота.
4. **Профили неполные.** У части людей пустые описания должностей и навыки. Таким Claude поставит «нет данных», а не «не подходит», и HR это увидит.
5. **Юридически.** Провайдеры — легальные компании, но источники у них разные. Перед покупкой:
   - запросить письменно, откуда данные и как соблюдается GDPR (а также DPA — договор об обработке данных);
   - у себя хранить минимум: имя, ссылку, балл, выжимку;
   - при первом контакте говорить, откуда узнали о человеке, и удалять данные по просьбе (требование GDPR, UAE PDPL, законов США).
6. **Контакты (email, телефон)** нам не нужны: цель — ссылка на LinkedIn, пишет HR. Это и дешевле, и чище юридически.

## 6. Предлагаемый пилот (1–2 дня, почти бесплатно)

1. Берём **одну реальную вакансию** (лучше для Дубая).
2. Регистрируете аккаунты: PDL (бесплатный тариф) и Coresignal (7-дневный триал). Ключи кладём в `.env`.
3. Прогоняем одинаковый поиск через оба сервиса по 50–100 профилей и оцениваем Claude.
4. HR смотрит топ-20 каждого и отмечает, сколько реально подходящих.
5. По итогу выбираем провайдера или решаем, что для этой роли лучше Recruiter + ручной канал.
